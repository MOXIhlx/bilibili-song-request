## v1.1.0 —— 面板样式改为命名样式体系

### 面板外观：从「单个全局样式」改为「命名样式列表」

`config.panel`（单个对象）→ `config.panel_styles`（数组）+ `default_style_id`。

早期只有一套全局样式，于是「歌词页一套配色、队列页另一套」只能靠 URL 参数逐个覆盖——地址长到 100~135 字符，改一次配色要在每个 OBS 浏览器源里重新复制一遍。

现在地址只写 `?style=<id>`（约 50 字符），**改一套样式，所有引用它的源一起生效**。旧配置自动迁移，保留原有配色。

### 导航统一为一条标签栏

```
[直播与播放][点歌队列][空闲歌单][点歌日志] │ [黑名单]  [设置][OBS 面板][背景图库]  [刷新状态]
```

顶栏不再有页级导航，首页底部的两个零散链接也已删除。

### 设置页三个子标签

`/settings`（基础）、`/settings/obs`（OBS 面板）、`/settings/background`（背景图库）。
OBS 面板页为双栏布局，右侧预览 400px 高且滚动时吸附。

### 背景图：网格缩略图 + cropperjs 裁剪编辑器

裁剪 / 左右转 90° / 水平垂直镜像 / 缩放 / 5 种宽高比；裁剪框可拖出图片边界（越界导出为透明）；变换烘焙进导出结果；**另存为新图**（原图保留）。删除改为移入 `backgrounds/.trash/`，可手工还原。

### 首页重排

「正在播放」移到首位（左上角）；B 站弹幕连接、音乐平台配好后折叠成一行状态；「链路自测（排障用）」移出首页到设置页。**首屏交互控件 35 → 13。**

### 修复的问题

- **大于 2 MB 的图片无法上传**：axum 默认请求体上限是 2 MB，请求在进入处理函数前就被拦成 413（响应体为空）。现已放宽到 40 MB，业务上限 32 MB 并给出带 MB 数的提示。
  实测修复前 600 KB ✅ / 2225 KB ❌ / 5800 KB ❌；修复后 0.7 / 2.54 / 6.57 / 13.53 MB 全部 ✅
- **「背景图库」页错误显示了 OBS 面板的样式/外观/预览**
- **配置迁移会产生重复样式**（serde 默认 id 撞名 + 迁移与规范化顺序颠倒）
