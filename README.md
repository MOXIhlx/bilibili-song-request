# 墨墨弹幕点歌机

B 站直播弹幕点歌工具。观众在直播间发送 `点歌 歌名 歌手`，程序自动搜索、排队、播放，
主播这边可以用 OBS 把「正在播放 + 点歌队列 + 歌词」直接叠在画面上。

- 支持 **网易云音乐** 与 **QQ 音乐**（搜索歌曲、获取播放地址、拉取歌词）
- 音频由 **mpv** 直接输出到系统声卡，**面板本身不出声**（OBS 里另加桌面音频采集）
- 面板是普通的网页，OBS 浏览器源、浏览器、甚至另一台设备的浏览器都能打开

---

## 安装

到 [Releases](https://github.com/MOXIhlx/bilibili-song-request/releases) 下载
`bilibili-song-request_<版本>_x64-setup.exe`，双击安装即可。

- **安装包已内置 mpv 播放引擎**，不需要再装别的东西
- 只需要系统有 **WebView2**（Windows 11 自带；Windows 10 缺的话安装程序会提示）
- 默认只装当前用户，**不需要管理员权限**

> 也有便携版 `*_portable_x64.zip`，解压即用，但**不含 mpv**，需要自备。

## 使用

### 1. 填写 B 站身份码

打开 [B 站直播开放平台](https://open-live.bilibili.com/) 申请，拿到
`app_id`、`access_key_id`、`access_key_secret`、`身份码` 四项，填进控制台的
「B 站弹幕连接」卡片，点「重新连接」。连接成功后卡片会显示直播间号与实时状态。

### 2. 登录音乐平台

在「音乐平台」卡片登录网易云音乐或 QQ 音乐（至少一个）。
不登录也能搜索，但**取不到播放地址**，点歌会失败。

### 3. 在 OBS 里加两块

| 类型 | 内容 | 作用 |
|---|---|---|
| 浏览器源 | `http://127.0.0.1:17777/panel` | 显示当前歌曲、队列、歌词 |
| 音频输入采集 | 桌面音频 | **让观众听到声音**（面板不出声） |

浏览器源建议勾选「透明背景」，并关闭「当源不可见时关闭」之类会卸载页面的选项。

面板地址只需要一个参数——用哪套**样式**：

```text
http://127.0.0.1:17777/panel?style=legacy
```

一套样式是一整套外观（主题、配色、布局、字号、背景图……）。在
**设置 → OBS 面板** 里调好并保存后，所有写了同一个 `?style=<id>` 的浏览器源
会一起生效；想给歌词页单独一套配色，就「从当前复制」再改。

不写 `?style=` 时用**默认样式**，所以只有一个面板源的话，直接用
`http://127.0.0.1:17777/panel` 就行。

还可以额外加 `scale=<倍率>`（例如 `&scale=1.3`）把某个源整体放大/缩小——
它只影响写了它的那个源，适合歌词页要更大的场景。

### 4. 点歌

观众在直播间发送：

```text
点歌 晴天 周杰伦
```

歌名必填，歌手可省略。命中后会进入点歌队列，按播放模式依次播放。

**设置 → 基础 → 链路自测** 里有输入框可以注入弹幕文本，方便自己先试。

## 控制台

程序的桌面窗口就是控制台，也可以在浏览器打开 `http://127.0.0.1:17777/dashboard`。

导航只有一条标签栏：左边是日常操作，右边是配置。

| 标签 | 用途 |
|---|---|
| 直播与播放 | B 站连接、音乐平台登录、正在播放、最近弹幕、最近点歌 |
| 点歌队列 | 查看 / 删除 / 拖动队列项 |
| 空闲歌单 | 没人点歌时自动播放的兜底歌单，可从收藏歌单导入 |
| 点歌日志 | 谁在什么时候点了什么、成功还是被拒 |
| 黑名单 | 拉黑用户或歌曲 |
| 设置 | 三个子标签：**基础**（服务器、点歌规则、搜索平台、链路自测）、**OBS 面板**（样式与面板地址）、**背景图库**（上传 / 裁剪背景图）|

播放模式在「正在播放」卡片上，点一下切换：**顺序播放 → 列表循环 → 单曲循环 → 随机**。

## 常见问题

**没有声音？**
OBS 里要加「音频输入采集 → 桌面音频」。程序故意让面板静音，音频只由 mpv 直接送到声卡。

**点歌提示「该歌曲无法获取播放地址」？**
通常是没登录音乐平台，或该歌曲受版权 / 会员限制。换一首或换平台试试。

**OBS 面板一片空白？**
先确认程序在运行，再用浏览器打开 `http://127.0.0.1:17777/panel` 看是否正常。
正常的话问题在 OBS 的浏览器源设置（透明背景、刷新）。

**B 站弹幕连不上？**
检查身份码四项是否都填对。日志在 `%APPDATA%\bilibili-song-request\logs\app.log`。

**换了一台电脑不能播放？**
安装包自带 mpv，正常不该出现。若确实报错，运行安装目录里的 `diagnose.bat`
会逐项检查并把结果打印出来。
